# Hifz Tajweed: recitation packages

Shaykh Ayman Suwayd's verse-by-verse recitation, in one package per para of the IndoPak 15-line mushaf
(`para01.zip` .. `para30.zip`, 23-28 MB each, 780 MB in all). Each package holds that para's ayah files
(`SSSAAA.webm`: surah and ayah number, Opus audio). `packs.json` gives each package's size, SHA-256 and
number of ayahs.

The Hifz Tajweed app (ஹிஃப்ழ் தஜ்வீத்) downloads a para's package from
`https://raw.githubusercontent.com/SwordSt0ne/hifz-mushaf-audio/main/paraNN.zip` the first time it is played,
and then plays it without internet. Please do not rename or move these files: the app looks for them here.
