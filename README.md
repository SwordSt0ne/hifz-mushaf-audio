# Hifz Tajweed: recitation packages

Shaykh Ayman Suwayd's verse-by-verse recitation, in one package per para of the IndoPak 15-line mushaf
(`para01.zip` .. `para30.zip`, 23-28 MB each, 780 MB in all). Each package holds that para's ayah files
(`SSSAAA.webm`: surah and ayah number, Opus audio). `packs.json` gives each package's size, SHA-256 and
number of ayahs.

The Hifz Tajweed app (ஹிஃப்ழ் தஜ்வீத்) downloads a para's package from
`https://raw.githubusercontent.com/SwordSt0ne/hifz-mushaf-audio/main/paraNN.zip` the first time it is played,
and then plays it without internet. Please do not rename or move these files: the app looks for them here.

## Shaykh Abu Bakr al-Shatri (`shatri/`)

Shaykh Abu Bakr al-Shatri's verse-by-verse recitation in the same form: `shatri/para01.zip` .. `shatri/para30.zip`
(16-21 MB each, 540 MB in all), each holding that IndoPak para's ayah files `SSSAAA.webm` (mono Opus, 40 kbps, made
from the 128 kbps files of everyayah.com, Abu_Bakr_Ash-Shaatree_128kbps), and `shatri/packs.json` (size, SHA-256 and
number of ayahs of each package). Hifz IndoPak Quran (1.6 on) downloads them from
`https://raw.githubusercontent.com/SwordSt0ne/hifz-mushaf-audio/main/shatri/paraNN.zip` when this reciter is chosen.
Please do not rename or move these files either.

## Shaykh Mishary Rashid Alafasy (`alafasy/`)

Shaykh Mishary Rashid Alafasy's verse-by-verse recitation in the same form: `alafasy/para01.zip` .. `alafasy/para30.zip`
(631 MB in all), each holding that IndoPak para's ayah files `SSSAAA.webm` (mono Opus, 40 kbps, made from the 128 kbps
files of everyayah.com, Alafasy_128kbps), and `alafasy/packs.json`. The Hifz apps (Hifz IndoPak Quran 1.8, Hifz
Tajweed Mushaf 1.6, Hifz Madina Mushaf 1.6 on) download them from
`https://raw.githubusercontent.com/SwordSt0ne/hifz-mushaf-audio/main/alafasy/paraNN.zip` when this reciter is chosen.
